# VIVY

An <b>Image Viewer</b> made with <b>C++</b> and <b>SDL</b>

### FEATURES:

- loads external images
- automatic sizing
- GPU rendering
- keyboard controls
- zooming
- event loop
- native windowing

### BUILD:

```sh
mkdir build
cd build
cmake ..
make
```

### USAGE:

```sh
./vivy <image-path>.jpg/.png
```
